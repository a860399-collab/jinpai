# 金牌一條根 LINE OA 半年自動貼文設計書

- LINE OA：@111wrvef
- 規劃期間：2026-06-04 至 2026-11-30
- 貼文量：每日 2 則，共 180 天、360 則
- 建議模式：半自動審核。系統產生草稿與圖片 brief，人工法規/藥師審核通過後才進入待發布。
- 發布時段：12:00 午間知識/生活保健；20:00 晚間產品教育/互動/使用安全。

## 一、設計原則

1. 產品定位採保守說法：外用反刺激型局部痠痛舒緩膏／乙類成藥型舒緩油膏。
2. 可講「局部按摩、暫時舒緩、依標示使用、成分透明、藥證可查」。
3. 不講「根治、治療疾病、消炎治本、深層修復、一擦就好、保證有效、替代藥物」。
4. 所有貼文預設 `pending_legal_pharmacist_review`，不得由 AI 直接發布。
5. LINE Messaging API 只負責到點送出；排程可靠性由雲端 n8n 或等效雲端自動化服務負責。

## 四、n8n / Google Sheets 欄位設計

建議把 CSV 匯入 Google Sheets 的 `03_貼文草稿佇列` 或新增 `半年排程佇列_360則` 工作表。n8n 每天 12:00 和 20:00 查詢當日、當時段、`review_status=approved` 且 `publish_status=ready` 的列，送 LINE broadcast。發送成功後寫回 `published_at`、`line_message_id`、`publish_status=published`。

關鍵欄位：`post_id`、`date`、`time`、`pillar_code`、`topic_title`、`risk_level`、`review_status`、`publish_status`、`prompt_brief`、`mandatory_disclaimer`。

## 六、法規與安全審核規則

- 高風險支柱 E 一律人工審核，不自動發布。
- 中風險支柱 A/C/D/H 需確認未擴大官方適應症，也不可暗示治療慢性病或神經/骨刺/退化性疾病。
- 若文案出現禁用詞，n8n 應自動改為 `review_status=needs_rewrite`。
- 若提到兒童、孕哺、過敏、抗凝血藥、破皮、傷口、熱敷、密封包紮，必須保留安全提醒。
