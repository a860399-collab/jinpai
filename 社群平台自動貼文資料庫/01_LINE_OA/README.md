# LINE 官方帳號 工作區

- 平台資料夾：01_LINE_OA
- 主要格式：圖片 + 短文 / Flex Message / broadcast payload
- 使用說明：LINE OA @111wrvef。主要使用每日 12:00 / 20:00 排程，n8n 到點 broadcast。
- 預設流程：AI 產生草稿 -> 法規/藥師/人工審核 -> 核准後排程或發布
- 合規底線：不得宣稱根治、治療疾病、消炎治本、立即見效、一擦就好、深層修復或替代藥物。

## 子資料夾

- `01_排程`：平台排程 CSV、Google Sheets 匯出檔、發布日期表。
- `02_待審核草稿`：AI 生成但尚未審核的文案與腳本。
- `03_已核准待發布`：人工審核通過，可交給 n8n 或人工排程。
- `04_已發布`：已發布版本與最終截圖/連結。
- `05_素材`：平台專用圖片、影片、封面、字幕檔。
- `06_成效追蹤`：觸及、互動、點擊、留言、收藏、轉換。
- `07_API或手動發布設定`：平台 API、權限、發布方式與注意事項。
