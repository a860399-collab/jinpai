## 使用步驟

1. **開啟 Claude 新對話**
2. **貼入 SYSTEM PROMPT**（固定角色設定那段）
3. **選擇對應的 USER PROMPT 模板**
4. **填入變數**（主題分類、角度、靈感等）
5. **送出，Claude 輸出完整貼文**
6. **複製「LINE 發布格式」那段**，準備發布
