# 社群平台自動貼文資料庫

建立日期：2026-06-03
品牌：金牌一條根
LINE OA：@111wrvef

## 目錄說明

- `00_共用法規與品牌資料`：產品法規、醫學文獻、共用禁用詞、品牌語氣。
- `01_LINE_OA`：LINE 官方帳號排程、草稿、素材、發布記錄。
- `02_Facebook`：Facebook 圖文、輪播、短影片資料。
- `03_Instagram`：Instagram Carousel、Reels、caption、素材。
- `04_Threads`：Threads 短文、問答、串文。
- `05_TikTok`：TikTok 短影音腳本、字幕、封面、發布資料。
- `06_抖音`：抖音短影音腳本、字幕、封面、發布資料。
- `07_跨平台模板與Prompt`：FB / LINE / IG / Threads / TikTok / 抖音共用改寫模板。
- `08_n8n與自動化流程`：n8n workflow、API schema、Google Sheets 欄位。
- `09_共用圖片與影片素材`：跨平台可重用素材。
- `10_成效追蹤總表`：跨平台成效整合。
- `99_封存`：舊版、停用或備份資料。

## 建議工作流程

1. 從半年排程佇列選出主題。
2. 用平台別模板產生各平台草稿。
3. 草稿先放入各平台 `02_待審核草稿`。
4. 人工審核通過後移到 `03_已核准待發布`。
5. 發布後存到 `04_已發布`，並在 `06_成效追蹤` 記錄表現。

## 合規提醒

所有平台都以「待法規/藥師/人工審核」為預設。不得由 AI 直接自動發布外用成藥相關文案。
