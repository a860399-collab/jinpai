## 二、下單流程（主流程）

### Step 1｜長輩點「我要訂購」或傳「訂購」

**Bot 回覆：**
```
🛒 請選擇您要購買的方案：

① 單支體驗 $350（+運費$150）
② 🔥 3+1組合 $1000（免運，最多人選）
③ 家庭大組 6瓶 $1800（免運）

請直接回覆數字 1、2 或 3
（或說出您想要哪個也可以 🎤）
```

---

### Step 2｜長輩回覆選擇（數字或語音）

**n8n 判斷：**
- 收到 `1` / `單支` / `一罐` → 記錄方案：單支 $350
- 收到 `2` / `3+1` / `三加一` / `一千` → 記錄方案：3+1組 $1000
- 收到 `3` / `六瓶` / `大組` → 記錄方案：6瓶 $1800
- 其他語音 → 送 Whisper 辨識後再判斷

**Bot 確認：**
```
✅ 好的，已選擇【3+1組合 $1000，貨到付款】

接下來填寫收件資料，只要 3 個步驟！

👤 請問收件人姓名？
（直接回覆文字，或按 🎤 說給我聽）
```

---

### Step 3｜收集姓名

**長輩回覆：** `王美玲` 或語音說出姓名

**Bot 確認：**
```
收到！收件人：王美玲 ✓

📱 請問手機號碼？（方便物流聯絡）
```

---

### Step 4｜收集手機

**長輩回覆：** `0912345678`

**n8n 驗證：** 是否為 09 開頭 10 碼數字
- 格式正確 → 繼續
- 格式錯誤 → 回覆：
```
⚠️ 號碼好像有點問題，麻煩再確認一次？
格式範例：0912345678
```

**Bot 確認：**
```
好的，手機：0912-345-678 ✓

🏠 請問收件地址？
（可以說給我聽，例如：「台北市信義區信義路五段七號」）
```

---

### Step 5｜收集地址

**長輩回覆：** 文字或 🎤 語音

**語音處理（n8n + Whisper）：**
1. 收到音訊檔
2. 送 OpenAI Whisper API 轉文字
3. Bot 顯示辨識結果讓長輩確認

**Bot 回覆：**
```
我聽到的地址是：
📍 台北市信義區信義路五段7號

請確認是否正確？
✅ 正確  ✏️ 重新輸入
```

---

### Step 6｜最終確認單

長輩點「✅ 正確」後，Bot 顯示：

```
📋 訂單確認

商品：3+1組合 × 1組（共4瓶）
金額：$1,000（貨到付款）
運費：免運

收件人：王美玲
手機：0912-345-678
地址：台北市信義區信義路五段7號

━━━━━━━━━━━━━━
確認後即送出訂單，請仔細核對 👆

✅ 確認送出   ✏️ 修改資料
```

---

### Step 7｜訂單成立

長輩點「✅ 確認送出」：

**n8n 執行：**
1. 寫入 Google Sheets（自動生成訂單編號）
2. 寄確認信給長輩 Email（若有填）
3. 推送通知給老闆（你）

**Bot 回覆：**
```
🎉 訂單成立！

訂單編號：JT-240001
（請截圖保存，或記住這個號碼）

📦 出貨時程：1～2 個工作天
💳 付款方式：貨到付款（收到再付）

有任何問題，直接傳訊息給我！
查詢進度請說「查訂單」📬
```

## 三、查詢訂單流程

### 長輩傳「查訂單」或點 Rich Menu

**Bot 回覆：**
```
🔍 訂單查詢

請輸入您的【訂單編號】
（格式：JT-xxxxxx，例如 JT-240001）

或輸入您的【手機號碼末4碼】
我幫您查詢最近的訂單 📋
```

**長輩回覆訂單號或末4碼 → n8n 查 Google Sheets → Bot 回覆：**

```
📦 訂單 JT-240001 狀態

商品：3+1組合 $1000
收件人：王美玲

目前狀態：🚚 配送中
物流單號：123456789
預計送達：6月8日（週六）

有問題請直接傳訊息，我會盡快協助！
```

## 四、常見問題自動回覆

| 長輩說 | Bot 回覆 |
|--------|---------|
| `成分` / `什麼成分` | 草本成分介紹文字 + 圖片 |
| `怎麼用` / `使用方法` | 3步驟使用說明圖 |
| `多久收到` | 「1-2 個工作天出貨，全台約 2-3 天收到」 |
| `可以退換嗎` | 退換貨說明 |
| `有沒有副作用` | 注意事項說明 |
| `謝謝` / `好的` / `收到` | 「不客氣！有需要隨時找我 😊」 |

## 五、老闆（你）的通知格式

每筆訂單成立，n8n 推播到你的 LINE：

```
🔔 新訂單通知

訂單：JT-240001
方案：3+1組 $1,000
姓名：王美玲
電話：0912-345-678
地址：台北市信義區信義路五段7號
時間：2024/06/06 14:32

→ 請至 Google Sheets 更新出貨狀態
```

## 六、狀態更新通知長輩

你在 Google Sheets 更新「狀態」欄位 → 觸發 n8n → Bot 主動推播：

| 狀態 | Bot 主動傳給長輩 |
|------|----------------|
| 已出貨 | 「📦 您的訂單已出貨！物流單號：XXXXXXX，預計明後天送達，請保持手機暢通 😊」 |
| 配送中 | 「🚚 物流已抵達您附近，今天會配送，請注意接聽電話！」 |
| 已送達 | 「✅ 訂單已送達！希望金太極對您有幫助，有需要歡迎再訂購 🙏」 |
