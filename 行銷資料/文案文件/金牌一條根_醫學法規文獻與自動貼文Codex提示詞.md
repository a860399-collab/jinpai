## 3. 醫學與藥理判斷

### 3.1 總結判斷

這個產品**不是完全沒效果**，但效果範圍有限。  
它比較正確的定位是：**外用反刺激型痠痛舒緩膏**。

可合理期待：

- 局部肌肉痠痛短期舒緩
- 肩頸僵硬不適短期舒緩
- 運動後局部不適舒緩
- 久站、久坐、搬重物後局部按摩舒緩
- 輕微關節痠痛舒緩
- 蚊蟲叮咬後局部癢感舒緩

不可期待：

- 根治退化性關節炎
- 消除骨刺
- 治療椎間盤突出
- 根治神經痛
- 修復軟骨、筋膜或韌帶
- 治療風濕免疫疾病
- 真正消炎治本
- 排毒、打通經絡、重建血液循環

### 3.2 主要有效成分

| 成分 | 角色 | 判斷 |
|---|---|---|
| 冬青油 | 主要活性來源 | 可能提供 methyl salicylate 類反刺激、局部止痛舒緩體感 |
| 薄荷腦 | 主要活性來源 | 清涼感強，刺激冷覺受器，干擾疼痛感受 |
| 樟腦 | 活性來源 | 反刺激、涼熱感、局部止癢止痛感 |
| 桉葉油 | 輔助感受 | 氣味、清涼感、舒緩體驗 |
| 薰衣草油 | 輔助感受 | 氣味、放鬆感、使用體驗 |
| 白蜜蠟 | 基劑 | 增稠、附著、形成膏體 |
| 凡士林 | 基劑 | 潤滑、保護、延展 |
| 親水基劑 | 基劑 | 乳化、延展、穩定 |
| 色素 | 外觀 | 無治療作用 |

## 7. 核心產品定位

### 7.1 一句話定位

> 不是神效一條根，而是成分透明、藥證可查的局部痠痛舒緩膏。

### 7.2 專業定位

> 本產品以冬青油、薄荷腦、樟腦作為主要舒緩體感來源，搭配凡士林、蜂蠟與親水基劑形成外用油膏劑型，適合局部肌肉痠痛、肩頸僵硬不適、運動或勞動後不適時按摩舒緩。

### 7.3 消費者白話定位

> 不是拿來治病的神藥，是肩頸、腰背、小腿痠的時候，拿來局部按摩、讓身體有涼感和舒緩感的外用膏。

### 7.4 差異化主軸

本產品不好賣的原因不是「完全沒效果」，而是市場同質化嚴重。  
要避免和一般一條根、青草膏、痠痛貼布、薄荷膏、樟腦膏直接打價格戰。

建議差異化：

1. **藥證可查**
   - 建立信任感。
   - 不走神效路線。

2. **成分透明**
   - 把冬青油、薄荷腦、樟腦講清楚。
   - 消費者知道自己擦的是什麼。

3. **高體感舒緩**
   - 涼感明顯、按摩有感。
   - 以「體感」而非「神效治療」作為賣點。

4. **場景化銷售**
   - 久站族
   - 開車族
   - 搬重物族
   - 運動族
   - 廟會陣頭／神將／扛轎族群
   - 長輩日常輕微不適

5. **安全用藥教育**
   - 別人都在喊神效，我們主動教消費者安全使用。
   - 建立藥廠感與專業感。

## 8. 目標客群與內容角度

### 8.1 久站服務業

- 情境：餐飲、門市、美容、美髮、市場攤商。
- 痛點：站整天，小腿、腰背痠。
- 文案方向：
  - 「站整天後，小腿和腰背需要局部按摩舒緩。」
  - 「下班後給身體一點清涼舒緩感。」

### 8.2 開車族／貨運族／業務族

- 情境：長時間開車、久坐、搬貨。
- 痛點：肩頸、腰背、手臂痠。
- 文案方向：
  - 「跑一整天，肩頸腰背緊繃，回家後局部按摩放鬆。」

### 8.3 運動族

- 情境：健身、跑步、球類、登山。
- 痛點：運動後肌肉痠痛。
- 文案方向：
  - 「運動後不是硬撐，局部痠痛可以按摩舒緩。」

### 8.4 廟會／神將／陣頭／扛轎族群

- 情境：練將、扛轎、出陣、繞境、長時間站立。
- 痛點：肩膀、腰背、大腿、小腿疲勞。
- 文案方向：
  - 「練將後、出陣後，身體緊繃不是小事。」
  - 「為傳統文化付出的身體，也需要好好照顧。」
  - 「扛轎、練將、站整天後，局部按摩舒緩。」

> 這是最適合做差異化的市場切角，因為一般痠痛膏品牌不會深耕這個場景。

### 8.5 長輩日常

- 情境：爬樓梯、散步、家務、農務。
- 痛點：肩頸、腰背、膝蓋輕微不適。
- 文案方向：
  - 「長輩日常輕微痠痛，可局部按摩舒緩。」
  - 必須補充：「若有紅腫熱痛、嚴重疼痛或長期不適，請就醫。」

```text
若出現禁用詞 → BLOCKED
若宣稱治療疾病 → HIGH
若描述過度接近療效保證 → HIGH
若只有局部舒緩與安全提醒 → LOW
若涉及官方適應症但容易誤解 → MEDIUM，需要人工複核
```

## 16. 最重要的商業結論

這個產品不好賣，不是因為完全沒效果，而是因為市場上「一條根、青草膏、痠痛貼布、薄荷膏」太多，消費者難以辨識差異。

真正的賣點應該從「神效」轉成：

1. 成分透明
2. 藥證可查
3. 涼感與按摩舒緩體感明顯
4. 場景明確：久站、久坐、運動、廟會陣頭、搬重物後
5. 安全使用教育
6. 不誇大、不亂喊根治

核心品牌語言：

> 不是神藥，是用在對的地方的局部舒緩膏。
